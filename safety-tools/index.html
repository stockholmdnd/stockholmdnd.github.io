Safety Tools

How to use this page#

While it isn’t a requirement for our Dungeon Masters to use Safety Tools it is strongly recommended. This document is a collection of tools to pick and choose from for a Dungeon Master. It is also a reference for players and budding Dungeon Masters.

The tools are grouped by pre-session tools that are ideally used before the game starts to set expectations, in-session tools to handle issues that occur in-game, and post-session tools to follow up on events after a session.

These tools can be used in any game, not just ours, nor D&D 5e/5.5e, but any TTRPG. In fact some of them, like Session 0, may well be better suited for long campaigns rather than our one-shots.

Guild events#

For our events part of Session Zero is handled through the event (scheduling, venue, snacks), through our rules document, and through the Dungeon Master’s presentation of the session/table. The description of the table will give the premise and set the tone. It may also contain trigger warnings or restrictions for the table. In the tables channel the Dungeon Master may present homebrew rules, and/or Safety Tools they will use.

Player Responsibility#

If you perceive that the Dungeon Master hasn’t expressed the tone or setting of the adventure to your satisfaction, and there are any topics, fears, or phobias, etc. that may trigger you as a player it is important that you bring it up with the Dungeon Master before the game.

If you are uncertain about a table it is advisable to contact the Dungeon Master before signing up in order to establish if it is for you or not. If it is a horror themed adventure the Dungeon Master may have a hard time adapting it without compromising the story and setting. In this case you would be better served by choosing another table.

Pre-session Tools#

Pre-session tools are typically tools to prepare before a game and set boundaries to avoid in-game issues.

Session Zero#

Session Zero is much much more than a Safety Tool, it sets the tone and premises, the rules and expectation, handles scheduling and much much more. But an important part of it is to inventory comfort levels and set boundaries. Session Zero is most likely overkill for a one-shot.
