Bot Commands

All commands are prefixed with &. Required parameters are shown in <angle brackets> and optional parameters in [square brackets].

&companions#

&companions [edition] [layout]

Render a graph of characters who’ve adventured with characters by edition.

The layout controls what the graph will look like, choose one of the available options if you want a different style.

Restriction: Not usable in #floating-sessions.

Parameters:

ParameterTypeRequiredDescription
edition'5.5e' | '5e'No (default: 5.5e)the edition to check for companions in - one of [‘5e’, ‘5.5e’]
layout'spring' | 'circular' | 'shell' | 'spectral' | 'spiral' | 'random'No (default: spring)[‘spring’, ‘circular’, ‘shell’, ‘spectral’, ‘spiral’, ‘random’]

&newsession#

&newsession <name> <limit> <tier> <blurb> <date> <start> [end] [edition]

Create a new floating session to DM (self-hosted).

Parameters:

ParameterTypeRequiredDescription

tierintYesthe level tier for the table
blurbstrYesthe adventure description - don’t forget “quotes”

startstrYessession start time - HH:MM
endstr | NoneNosession end time - HH:MM
edition'5.5e' | '5e'No (default: 5.5e)The D&D edition

&newtable#

&newtable <name> <tier> <blurb> [restrictions]

Create a new table to DM.

Example usage: &newtable "Into the Underdark" 5 "A perilous journey through the caverns beneath the world, filled with unspeakable horrors and unimaginable treasures." "No evil characters allowed"

Note that the name, blurb and restrictions have to be surrounded by quote characters ("), it can’t be smart quotes (”) that some keyboards, typically on mobile devices produce.

The restrictions can be anything that the DM wants to disallow for this adventure (e.g. ’no evil characters’, ‘must be a warlock’, etc.). This is an optional field.

Access: Requires the Dungeon Master role. Restriction: Not usable in #floating-sessions. Restriction: Only usable in channels under the Event Channels category.

Parameters:

ParameterTypeRequiredDescription
namestrYesthe name of the adventure
tierstrYesthe level tier for the table
blurbstrYesthe description of the adventure
restrictionsstr | NoneNoAny restrictions or houserules for the table

&table#

Parameters:

valuestr | intYesThe new value of the field. For remove_player, use @mention.

&info#

&info [i]

Edit text in info channels. The text that should be used is stored in the folder copytext. The role channels are rules-n-regs and dm-rules-n-regs. The info channel is welcome. In the role channels, only messages with index 0 to 2 can be edited. In the info channels, any message can be edited. In the role channels, if no index is provided, a new message will be appended with the provided text.

Access: Requires the Admin role. Restriction: Only usable in #welcome, #rules-n-regs, #dm-rules-n-regs.

Parameters:

ParameterTypeRequiredDescription
istr | NoneNoThe index of the message to edit

&infoinit#

&infoinit

Initialize an info channel. It create 3 messages that will then have to be filled with with &info command. The info channels rules-n-regs and dm-rules-n-regs. The last mesage always has a &(:dnd:) emoji reaction that grants the appropriate role.

Access: Requires the Admin role. Restriction: Only usable in #rules-n-regs, #dm-rules-n-regs.
